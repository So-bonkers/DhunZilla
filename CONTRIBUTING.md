# Contributing to DhunZilla

Thanks for your interest! A few things to know first:

- **Issues, bug reports, ideas and discussion are very welcome.**
- **Code contributions from outside the project are not accepted yet.** Before we can accept them we need a
  Contributor License Agreement (CLA) in place; see [ADR-0008](docs/adr/0008-out-of-process-plugins-and-cla.md).
  This keeps future licensing options open while the project finds its footing.
- **Extensions will be plugins.** DhunZilla is designed so that new features — including AI features — run as
  separate plugin processes over a public protocol. Once that protocol exists (planned for the "Real DAW" phase),
  building a plugin will be the easiest way to extend DhunZilla without touching the core.
- How the project is built: all code is written by coding agents under the rules in [AGENTS.md](AGENTS.md); the
  roadmap is in [ROADMAP.md](ROADMAP.md).
